# Portfolio – Kailash Murali T

A personal portfolio website built with plain HTML, CSS, and JavaScript.

## How to run

The workflow "Start application" serves the site with Python's built-in HTTP server on port 5000:

```
python3 -m http.server 5000
```

No dependencies or build step needed — just static files.

## Project structure

| File | Purpose |
|---|---|
| `index.html` | All page markup |
| `portfolio.css` | All styles |
| `portfolio.js` | Interactions (dark mode, typing effect, circle cards, contact form) |
| `profile.jpg` | Profile photo shown in the About card |
| `logo.jpg` | Browser tab favicon |

## Notes

- Designed for desktop; mobile support is in progress (see README).
- The Contact form UI exists but is not yet wired to an email service.
