STACKING ORDER & TRANSFORMS (initial state):
Each panel has a z-index based on its position in the deck.
The ACTIVE panel is always on top (z-index highest).
Panels BELOW the active panel peek out from behind using a
subtle scale + translateY offset — like physical cards in a stack.

Panel state machine:
  · "active"   — z: 50, scale: 1,    y: 0,    opacity: 1
  · "below-1"  — z: 49, scale: 0.97, y: 12px, opacity: 1     (directly under active)
  · "below-2"  — z: 48, scale: 0.94, y: 22px, opacity: 0.85
  · "below-3"  — z: 47, scale: 0.91, y: 30px, opacity: 0.7
  · "below-4"  — z: 46, scale: 0.88, y: 36px, opacity: 0.55
  · "exited-up"— z: 45, scale: 1.04, y: -100vh, opacity: 0   (panels already visited, fly off top)

LEAF TURN ANIMATION (Framer Motion):
When advancing to next section (knob rotated clockwise):
  1. Active panel animates OUT: scale 1 → 1.04, y 0 → -100vh, opacity 1 → 0
     duration 0.55s, ease [0.4, 0, 0.2, 1]
  2. All below panels simultaneously shift up one slot:
     below-1 → active, below-2 → below-1, etc.
     duration 0.55s, ease [0.34, 1.2, 0.64, 1] (slight spring for satisfying lift)
  3. The newly active panel scales from 0.97 → 1.0 with a subtle y 12 → 0

When going BACK (knob rotated counter-clockwise):
  1. The current active panel drops back to below-1 position
     scale 1 → 0.97, y 0 → 12px, duration 0.45s
  2. The previous panel flies in from y: -100vh → 0, scale 1.04 → 1
     duration 0.55s, ease [0.34, 1.2, 0.64, 1]

Use Framer Motion `motion.div` with `animate` prop driven by JS state.
Use `useReducer` or `useState` to track `activeIndex` (0–4).
Derive each panel's visual state from `activeIndex` on every render.

The bottom edge of the stacked cards must be visible at the bottom of
the viewport as thin colored slivers — achieve this by applying the
scale+y transforms from the BOTTOM of the panel:
  transform-origin: center bottom on all panels
This makes the stack peek out from the bottom like a deck of cards
held in a hand, not from the top.
